# 数学可视化模式参考

## 2D 函数图形

### 基础函数
- 多项式函数：抛物线、三次曲线
- 三角函数：sin/cos/tan 波形图
- 指数/对数函数：增长/衰减曲线
- 参数方程：心形线、摆线、螺旋线

### 微积分可视化
- 切线与法线动画（拖动切点移动）
- 黎曼和逼近（矩形数量可调）
- 面积着色（定积分几何意义）
- 旋转体生成动画（面绕轴旋转 → 3D体）
- ε-δ 极限直觉动画

## 3D 曲面与曲线

### 二次曲面族
- 椭球面：参数 a, b, c 可调
- 双曲面：单叶/双叶切换
- 抛物面：旋转/双曲抛物面
- 圆锥面：半角可调
- 圆柱面：半径可调

### 多元微积分
- 二元函数曲面图
- 等高线图 + 梯度向量场叠加
- 曲面截面（固定 x/y/z 截面动态显示）
- 切平面动画
- 方向导数箭头

### 空间曲线
- 螺旋线、Viviani曲线
- Frenet标架动画（T, N, B 向量）
- 曲率/挠率可视化

## 线性代数可视化

### 矩阵变换
- 2D 网格变形动画
- 特征向量方向高亮
- 行列式面积/体积变化
- SVD 分解三步动画

### 向量空间
- 基向量表示
- 线性组合交互（拖动系数）
- 子空间平面/直线
- 正交投影动画

## 概率统计可视化

### 分布曲线
- 正态分布：μ, σ 参数滑块
- 二项分布：n, p 参数动态直方图
- 泊松分布：λ 参数调节
- 面积着色（概率计算区域）

### 统计推断
- 置信区间可视化
- 假设检验临界区域
- 回归直线拟合动画

## 微分方程可视化

### 方向场
- 向量箭头密布平面
- 解曲线叠加显示
- 初值条件交互（点击设起点）

### 相平面
- 相轨线动画
- 平衡点分类（稳定/不稳定/鞍点）
- 向量场着色

## 动画效果

### 幻灯片过渡
- slide-left / slide-right：水平滑动
- fade：淡入淡出
- zoom：缩放切入
- none：无动画（快速浏览）

### 元素入场
- fade-in-up：从下向上淡入
- fade-in-left/right：从侧方淡入
- scale-in：从小到大缩放
- typewriter：打字机效果（文字）

### 公式推导
- 逐行渐显：每步公式依次出现
- 高亮变化：新增部分高亮显示
- 擦除替换：旧表达式渐隐，新表达式渐显
